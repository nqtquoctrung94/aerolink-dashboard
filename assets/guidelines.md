This dashboard provides a comprehensive view of airline performance across the AeroLink Alliance network from 2022–2025. Use it to monitor key metrics, compare airlines, and track performance trends.

**Navigation**
- Left sidebar: select Home, Airlines, Flights, or Fleet views
- Date controls: click the year ('22–'25) and month buttons (J, F, M, A…)
- Region filter: dropdown to change geographic focus ("Global" = all regions)
- Airline filter: select a specific airline (Flights and Fleet pages)

**Home**
- Alliance-wide performance metrics with monthly trends
- Regional comparisons and top destinations
- Aircraft utilization and operational KPIs

**Airlines**
- Summary section: key metrics (flights, distance, on-time %, satisfaction)
- Hub information: primary airport locations
- Major routes: top flight paths
- Traffic charts: passenger, cargo, and revenue metrics with monthly trends
- Performance indicators: green/red arrows show month-over-month changes

**Fleet**
- Aircraft cards: all aircraft types — click *View details* on a card
- Utilization stats: right panel shows the selected aircraft's performance

**Flights**
- Flight list: recent flights with dates, flight numbers, and routes
- Route map: geographic view of the flight path
- Interactive selection: click a flight row to see its route on the map

**Reading the trend tiles** — bars show each month of the selected year (selected month in blue).
Dots compare each month with the same month of the prior year: green = higher, red = lower, grey = equal / no data.
